1.0.0
    * Consolidate package metadata and tox configuration in setup.cfg and
      move mypy settings to pyproject.toml.
    * Add Python 3.14 and 3.15 to the test matrix and publish HTML coverage.
    * Preserve Pyramid compatibility on Python 3.7–3.9 with setuptools<82.
    * Use the Black pre-commit mirror.
    * Migrate pytest warning filters to valid TOML so tox can build the package.
    * Retain OAuthlib 3.2.2 as the minimum. The OAuth flow suite passed with
      OAuthlib 3.2.2, 3.3.1, and 4.0.1 on Python 3.14.6. See TESTING.txt for
      the compatibility and typing findings.
    * Require bearer tokens to include every scope required by the resource.
    * Remove OAuth credentials from diagnostic output and use a generic
      server_error for unexpected OAuth2 endpoint failures.
    * Require confidential client authentication and enforce token ownership
      during OAuth2 revocation. Search both token types when needed and return
      success for tokens unavailable to the requesting client.
    * Verify OAuth2 authorization error redirect destinations and check grant
      ownership when the storage backend exposes the issuing client.
    * Honor rejected OAuth1 nonce claims and document the atomic storage
      requirement. The SQLite example uses a unique nonce index.
